Source Sans 3, version 3.052, by Adobe, licensed under the SIL Open Font License.

The local WOFF2 is a Latin subset of Google Fonts' `ofl/sourcesans3/SourceSans3[wght].ttf`, with the variable weight range limited to 400–700. It includes French accents, French ligatures, currency symbols, typographic spaces, arrows and the minus sign. The font loads from this site; it makes no request to a third-party font service.

Source: https://github.com/google/fonts/tree/main/ofl/sourcesans3

The unchanged license is in `OFL-Source-Sans-3.txt`.
